# Probability and Random Variables Programming Assignment

Implementation of programming assignments for the **AI1110: Probability and Random Variables** course. The repository focuses on implementing fundamental random variable generation and Monte Carlo algorithms **from first principles**, using only uniformly distributed random numbers generated by `numpy.random.rand()`.

The assignment intentionally prohibits the use of built-in sampling utilities such as `numpy.random.normal`, `numpy.random.exponential`, and related routines, requiring every probability distribution and sampling algorithm to be constructed algorithmically.

---

## Overview

This repository contains implementations of several classical techniques used in probability, stochastic simulation, and statistical computing, including:

* Random variable generation from uniform randomness
* Inverse transform sampling
* Rejection sampling
* Box–Muller Gaussian generation
* Importance sampling for rare-event estimation
* Empirical CDF construction
* Central Limit Theorem verification
* Multivariate Gaussian simulation
* Empirical covariance estimation

Each implementation is accompanied by numerical verification and visualization using NumPy and Matplotlib.

---

## Assignment Structure

### 1. Generating a Biased Coin from a Fair Coin

Implements a Bernoulli random variable with arbitrary probability (p) using only repeated fair coin tosses generated from uniform random numbers.

Features:

* Fair coin simulator
* Biased coin generation using binary expansion of probability
* Empirical probability verification
* PMF visualization
* Analysis of average number of fair coin tosses required

---

### 2. Inverse CDF and Rejection Sampling

Implements sampling from continuous probability distributions without built-in generators.

Includes:

* Exponential random variable generation using inverse transform sampling
* Custom empirical CDF implementation
* Rejection sampling for a target density
* Acceptance rate computation
* Histogram comparison with theoretical density
* Empirical mean and variance estimation

---

### 3. Importance Sampling for Rare-Event Estimation

Studies estimation of


$P(X > 4), \qquad X \sim \mathcal{N}(0,1)$


using two approaches:

* Direct Monte Carlo estimation
* Importance Sampling with shifted Gaussian proposal

The implementation compares:

* Probability estimates
* Importance weights
* Sample mean
* Sample variance over repeated experiments

to demonstrate the variance reduction achieved through importance sampling.

---

### 4. Central Limit Theorem Verification

Verifies the Central Limit Theorem numerically using repeated sampling.

Implemented components include:

* Sample generation from a discrete distribution
* Sample mean computation
* Empirical CDF construction
* Gaussian approximation using Box–Muller generated samples
* Visual comparison between empirical and limiting distributions

---

### 5. Multivariate Gaussian Random Variables

Generates multivariate Gaussian random vectors using linear transformations.

Features include:

* Standard Gaussian generation via Box–Muller transform

* Linear transformation

  [
  Y = AX + b
  ]

* Empirical CDF comparison for individual components

* Empirical covariance estimation

* Mean squared error analysis between empirical and theoretical covariance matrices across varying sample sizes
